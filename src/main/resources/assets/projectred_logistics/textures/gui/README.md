# Sorting Machine GUI icon provenance

`sorting_machine_icons.png` is a repacked copy of the original 14x14
Sorting Machine mode-control icons from the RedPower 2 2.0pr6
(Minecraft 1.4.7) `sortmachine.png` GUI asset supplied by the user for
development reference.

The pixels are preserved so the controls remain recognizably RP2. The atlas
layout was changed only to make modern rendering simpler. This derived asset is
not intended to be covered by the repository's MIT license; rights in the
original RedPower 2 artwork remain with its original copyright holder(s).
