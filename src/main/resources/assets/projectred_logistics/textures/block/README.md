# Filter texture provenance

The Filter block textures in this directory are modified derivative textures
based on the RedPower 2 2.0pr6 (Minecraft 1.4.7) machine texture atlas supplied
for development reference.

They preserve the original Filter pixel geometry while using a recoloured
ProjectRed Logistics palette. These texture assets are not intended to be
covered by the repository's MIT license; rights in the original RedPower 2
artwork remain with its original copyright holder(s).
