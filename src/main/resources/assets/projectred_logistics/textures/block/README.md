# RedPower-derived block texture provenance

The Filter and Sorting Machine block textures in this directory are modified
derivative textures based on the RedPower 2 2.0pr6 (Minecraft 1.4.7)
`machine1.png` texture atlas supplied by the user for development reference.

## Filter

The Filter textures preserve the original Filter pixel geometry while using a
recoloured ProjectRed Logistics palette.

## Sorting Machine

The Sorting Machine uses the original RP2 sorter face geometry recovered from
the 1.4.7 renderer/atlas mapping:

- tile 112: opposite/end cap
- tile 113: normal machine cap
- tile 116: inactive body
- tile 118: active body

The original red/blue circuit traces are shifted to teal and copper/amber, with
a subtle cool-steel adjustment to the neutral machine body. The pixel geometry
and shading structure remain derived from the original RP2 artwork.

These derivative texture assets are not intended to be covered by the
repository's MIT license; rights in the original RedPower 2 artwork remain with
its original copyright holder(s).
